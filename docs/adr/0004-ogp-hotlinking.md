# ADR-0004: OGP画像はホットリンクで運用

- **状態**: Superseded by ADR-0011
- **決定日**: 2026-05-28

> **注記(2026-06-02)**: ADR-0011 でフィードカードを OGP 画像なしのテキスト主体に刷新したため、
> 本 ADR のホットリンク方針はフィード一覧では使われなくなった。
> プレースホルダー生成 API `/api/og/[id]` は残存するが、カードからは参照しない。
> 将来サムネイル付きカードへ戻す場合は本 ADR の検討が再び有効になる。

## 背景

カード表示には OGP 画像が必要(タイトルだけよりUIリッチ)。OGP画像の配信方針には複数ある:

1. ホットリンク(元サイトURLを直接 `<img src>`)
2. 自前ストレージにコピー保存
3. 画像プロキシ・最適化サービス経由

コスト・著作権・パフォーマンス・実装工数を総合判断する必要があった。

## 検討した選択肢

### A. ホットリンク

- 実装コスト: ほぼゼロ
- ストレージ不要、$0
- 元サイトの画像URL変更でリンク切れ
- 元サイトに帯域負荷を与える
- CDN効果が弱い(元サイトのCDN依存)

### B. 自前にコピー(S3 / R2 / Vercel Blob)

- 安定して配信可能
- ストレージコスト発生(Vercel Blob は無料1GB、超で課金)
- 著作権の扱いがグレー(画像をコピーして再配信)
- 取得失敗時のフォールバック実装が必要

### C. 画像プロキシ(Cloudinary / Vercel Image Optimization)

- 自動リサイズ、WebP変換
- 元URL を引数で渡せばCDN化
- 無料枠超過リスクあり
- 外部サービス依存

## 決定

**A. ホットリンク** を採用。

理由:
1. 個人開発でコスト最小化が最優先
2. 著作権的にもグレーを避ける(ユーザーが元サイトURLにアクセスする時と同じ参照のみ)
3. Next.js Image の `remotePatterns` で各社ドメインを許可、最適化のメリットは活かす
4. リンク切れ時は企業ブランドカラーのプレースホルダーで代替

## 結果

- ✅ MVP実装コスト最小、追加サービス不要
- ✅ ストレージコスト $0
- ⚠️ 各社の画像CDNに帯域依存(原則 大手企業なので大丈夫だが、小規模ブログ追加時は注意)
- ⚠️ 各社のドメインを `next.config.ts` の `remotePatterns` に追加するメンテが必要
- ❌ 元サイトが画像URLを変更すると過去記事の画像が表示できなくなる
- ❌ OGP取得失敗時の代替UIが必要(プレースホルダー生成)

## 将来の選択肢

トラフィックが増えて元サイトに迷惑をかけそうな兆候があれば、(C) Vercel Image Optimization か Cloudflare Images に切替を検討。
