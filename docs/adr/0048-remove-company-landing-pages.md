# ADR-0048: 企業ページ(/companies)を廃止する

- **状態**: Accepted
- **決定日**: 2026-11-07
- **関連**: ADR-0030(これを置き換える), ADR-0039(公開 RSS), ADR-0028(SEO ベースライン)
- **Supersedes**: ADR-0030

## 背景

ADR-0030 で、「〇〇 技術ブログ」系の検索流入を狙う着地ページとして `/companies`(ハブ)と `/companies/[slug]`(企業ごとの記事まとめ)を作った。
オーナーの判断で、企業ページによる SEO 施策は不要になった(Issue #28)。企業で絞った一覧はフィードの `/?company=<slug>` でも見られるので、ページを残す理由もない。
企業ページを残すと、フィードとは別の一覧(購読スコープ非依存の記事取得、専用の続き読み込み)を保守し続けることになる。

## 検討した選択肢

### A. ページを残し、SEO の仕組みだけ外す(sitemap から外し noindex)

- 既存の URL が生き続ける
- 使われない一覧と専用の読み込み経路の保守が残る

### B. ページごと消し、フィードの企業絞り込みに寄せる(採用)

- 企業ページ専用の合成(`getCompanyArticles`)・続き読み込み(`loadMoreCompanyArticles` / `LoadMoreTrigger`)・グリッド・JSON-LD ビルダを消せる
- 旧 URL はリダイレクトで受ける

## 決定

**B** を採用する。

- `/companies` と `/companies/[slug]` のページ、企業ページ専用の部品、sitemap のエントリ、企業ページの構造化データを削除する
- 旧 URL は `next.config.ts` の `redirects()` で恒久転送する: `/companies` → `/`、`/companies/<slug>` → `/?company=<slug>`
- 記事ページの企業名のリンク先を `/?company=<slug>` にする
- 企業別 RSS(`/companies/[slug]/feed.xml`、ADR-0039)は購読している RSS リーダーを壊さないよう残す。チャンネルの `link` は `/?company=<slug>` にする

## 結果

- ✅ 企業ページ専用の取得・表示経路がなくなり、記事一覧の実装はフィードに一本化される
- ✅ 旧 URL へのアクセスや外部リンクはリダイレクトで企業絞り込みのフィードに着地する
- ⚠️ 企業名での検索流入は期待しない。フィードのトップ(`/`)は canonical を `/` に固定しているので、企業絞り込みはインデックスされない
- ⚠️ 企業別 RSS だけが `/companies/` 配下に残る。URL を移すなら、購読者向けの転送を別途考える
