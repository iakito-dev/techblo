# ADR-0011: Base44 参照デザインへの刷新(インディゴ配色 + テキスト主体カード)

- **状態**: Accepted
- **決定日**: 2026-06-02
- **関連**: ADR-0004 (Supersedes), ADR-0005
- **一部 Superseded by**: ADR-0035

## 背景

MVP の UI は当初、ウォーム系(クリーム背景 + オレンジアクセント)のデザイントークンと、
OGP 画像つき・サイドバー/ウィジェットを持つ3カラムのリッチなフィードで設計されていた
(`design/mockup.html` ・ ADR-0004)。

その後、ノーコード AI ビルダー(Base44)で生成したデザイン案を参照デザインとして採用する方針となり、
それに実装を合わせることになった。Base44 案は次の特徴を持つ:

- クール系の配色(白背景 + インディゴ `#4f46e5` アクセント)
- カードは **OGP 画像なし** のテキスト主体(企業ブランドカラーのアクセントバー + メタ + タイトル + 抜粋)
- サイドバー/右ウィジェット/検索を持たない、見出し + 並び替え + 均一カードグリッドのシンプル構成
- フォントは Latin = Inter、日本語 = Noto Sans JP

この変更は配色・タイポグラフィ・カード構造・レイアウトに広く影響するため、記録する。

## 検討した選択肢

### A. 既存デザイン(ウォーム + オレンジ、OGP画像つき3カラム)を維持

- 既に design.md / mockup.html / ADR-0004 と整合
- OGP 画像でビジュアルがリッチ
- サイドバー/ウィジェットで情報量が多い
- Base44 で気に入った新デザインと乖離する

### B. Base44 参照デザインへ全面的に寄せる(採用)

- 配色をインディゴへ全面置換(brand 色は企業別に維持)
- カードをテキスト主体に(OGP 画像を廃止)
- レイアウトを簡素化(サイドバー/ウィジェット/検索を撤去)
- フォントを Inter + Noto Sans JP に
- MVP のスコープ(検索・企業追加は範囲外)にむしろ素直
- design.md / feed.md / mockup.html の更新が必要

## 決定

**B. Base44 参照デザインへ寄せる** を採用。

理由:
1. 気に入った参照デザインがあり、それを「正」とする方が意思決定が速い
2. テキスト主体カードは情報密度が高く、OGP 取得・画像最適化・リンク切れ対応の複雑さを排除できる
3. サイドバー/検索/企業追加は MVP スコープ外であり、簡素化が仕様と整合する

## 結果

- ✅ 配色・タイポ・カード・レイアウトが参照デザインに統一された
- ✅ カードから OGP 画像を外したことで、`next/image` の `remotePatterns` メンテや取得失敗時の挙動が一覧表示の関心事から外れた(ADR-0004 を Supersede)
- ✅ レイアウト簡素化で `feed-sidebar` / `feed-widgets` / `featured-card` を削除、保守対象が減った
- ⚠️ `design/mockup.html` のレンダリング部分(画像つきカード等)は旧デザインのまま残存。実装が真実の源であり、mockup は段階的に追随させる
- ⚠️ プレースホルダー生成 API `/api/og/[id]` は当面残すが、フィードカードからは参照しない
- ❌ OGP 画像によるビジュアルのリッチさは捨てた(将来サムネイル付きカードに戻す余地はある)
